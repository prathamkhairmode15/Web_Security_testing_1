Key Vulnerabilities & Findings

  • SSL/TLS Configuration: SSL Labs assigned a Grade T due to certificate trust and validation issues. Trust chain issues may affect client trust. TLS 1.3 is not supported.
  • Missing Security Headers: Several modern HTTP security headers are absent, reducing protection against common web attacks such as clickjacking, MIME-type confusion, content injection, and information leakage.
  • Exposed Services: Multiple web services are exposed on ports 80, 443, and 8080 (Apache Tomcat/Coyote JSP Engine 1.1).
  • Server Fingerprint Exposure: Detailed server banners (e.g., Apache-Coyote/1.1) are exposed, aiding attackers in version-specific exploitation.
